# Closed-Loop Open-Set Capability Expansion V9 Plan

## Phase 0: Freeze the corrective contract

- Commit `V9_SPEC_ADDENDUM.md`, `V9_PLAN.md`, `V9_CORPUS_RULES.md`, and
  `V9_BASELINE_PROTOCOL.md` with an exact SHA-256 manifest and executable test.
- Bind the committed V8 retirement object and require `held_out_opened=false`.
- Freeze schemas, enums, budgets, stage order, exposure-cohort rules, sibling
  preservation, terminal states, and key locations before authoring.
- Review the exact staged contract with Prism and remediate every high/medium
  finding before the freeze commit.

## Phase 1: Fresh isolated author packets

- Generate six checksum-bound packets with disjoint fixed assignments.
- Dispatch six fresh isolated authors only after explicit authorization.
- Each author returns four discovery and four held-out behavior-only
  requirements plus exact-template authorship provenance.
- Validate packet identity, JSON contract, references, bounds, quotas,
  diversity, semantic uniqueness, exact file sets, and full-byte hashes.
- Replace an invalidated author context; never repair isolation by workaround.

## Phase 2: Adjudicate and publish the corpus

- Adjudicate public electrical meaning without synthesis or feasibility tools.
- Permit only outcome-neutral contract corrections inside frozen boundaries.
- Run aggregate validation without exposing held-out contents.
- Create a new external 0600 V9 source key and atomically publish exactly 24
  public discovery records plus 24 record-encrypted held-out records.
- Authenticate publication independently before removing all V9 quarantine
  plaintext and superseded bundles.

## Phase 3: Freeze generation zero

- Freeze evaluator, inventory, model registry, simulation policy, installed
  KiCad environment, seeds, worker count, locale, and resource bounds.
- Evaluate 24 discovery cases twice; promote every pass twice from clean roots.
- Publish per-case evidence, outcome aggregate, obligation commitments, and
  complete typed root frontiers.
- In isolation, create a distinct external 0600 baseline key and publish only
  encrypted held-out baseline records plus non-revealing aggregates.

## Phase 4: Rank with complete exposure

- Enumerate complete candidates without truncation.
- Derive direct/closure atoms and members, fully covered cases, all exposed
  cases, selected paths, and nonselected sibling paths.
- Rank with unlock/diversity first and collateral exposure/sibling burden next.
- Publish the full semantic co-rank-one set and deterministic fallback.
- Freeze the selected effect plan, exposure cohort, sibling commitments, and
  implementation plan before any production edit.

## Phase 5: Implement the selected generic capability

- Change only generic production and verification paths mapped by the seal.
- Add representative, adversarial, boundary, determinism, fail-closed, and
  outcome-neutral sibling-preservation tests.
- Do not synthesize or inspect V9 corpus outcomes while implementing.
- Run focused and full local tests, vet/lint, historical regressions, and all
  installed-KiCad protected fixtures.
- Prism-review, remediate, commit, and publish the reviewed implementation seal.

## Phase 6: Exactly-once public advancement

- From a clean committed tree, run all 24 discovery cases exactly twice.
- Promote every pass twice and atomically publish success or retirement.
- Enforce exposure completeness, selected lineage, exact sibling preservation,
  non-exposed-case invariance, regression rules, environment seals, and budgets.
- On public admission, stop public iteration. On admissible continuation, freeze
  a new ranking/selection/plan before round two. Any other result retires V9.

## Phase 7: Blind final or retirement

- Never open held-out final material after public retirement.
- After public admission only, authorize one isolated custodian to use distinct
  source, baseline, and final 0600 keys.
- Evaluate all 24 held-out cases and publish encrypted records plus only the
  frozen non-revealing aggregate result.
- Authenticate the terminal artifact, remove temporary plaintext, run local
  verifiers, update durable documentation, Prism-review, commit, and push.
