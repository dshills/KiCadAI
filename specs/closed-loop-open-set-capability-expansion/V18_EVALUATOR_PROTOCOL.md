# V18 Low-Voltage Multi-Output Evaluator Protocol

Authenticate the V17 evaluator manifest, immutable V10 discovery corpus, V18
contract, and V18 evaluator manifests before execution. Run only from a clean
committed repository into a fresh output root.

V18 reuses the frozen V17 serial two-replay transport and therefore preserves
its clean-root marker, checkpoint, streaming, garbage-collection, and
fail-closed semantics. The environment digest binds the distinct V18 catalog,
model provenance, primitive inventory, and evaluator manifest. Requirements
outside the bounded low-voltage, high-input-impedance, multi-output threshold
capability delegate byte-for-byte to `SynthesizeV17`.

Eligible requirements use only the reviewed V18 extension: compatible
low-voltage active-part selection, deterministic merged-output retention,
closed-loop unity-buffer correction, contention-free diode-wired comparator
conjunction, high-impedance endpoint access, coupled threshold-value selection,
and bounded nonzero DC input-impedance probing. No semantic ID, fixture path,
coordinate, expected outcome, or held-out datum may influence these operations.

Evaluate all 24 public discovery cases in manifest order exactly twice. A
passing synthesis must complete existing physical lowering and both installed-
KiCad promotion roots with clean ERC, strict DRC, connectivity, route
completion, writer correctness, and zero round-trip differences. Any replay,
promotion, environment, corpus, manifest, or output inconsistency fails closed.

Held-out source keys, baseline keys, encrypted records, and blind outcomes are
outside this protocol and must not be opened.
