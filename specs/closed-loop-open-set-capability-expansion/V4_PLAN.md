  rules, baseline protocol, exact evaluator/impact/synthesis policies, contract
  tests, and checksums.
- Prove adversarial boundary behavior of the gap partial order.
- Confirm that no V4 requirement was authored or synthesized before this

## Phase 1: Independent corpus freeze

- Give a context-isolated author only the committed public authoring packet.
- Receive candidate files into quarantine without synthesis access.
- Perform public electrical sanity review and mechanical schema, vocabulary,
  provenance, uniqueness, non-overlap, quota, acceptance, and diversity checks.

- Keep held-out content inaccessible to the implementation context.

- Require byte-identical normalized evidence and promote baseline passes twice
  through clean installed-KiCad roots.

- Atomically seal the complete deterministic ranking and rank-one expansion
  plan.

## Phase 3: Held-out baseline seal

- Produce authenticated encrypted held-out baseline evidence without exposing
  case content, per-case outcomes, gaps, or diagnostics.
- Commit ciphertext and non-sensitive commitments only.

## Phase 4: Selected generic capability

- Implement only the sealed rank-one capability and inseparable generic
  prerequisites.
- Add representative, boundary, adversarial, deterministic replay, and
  fail-closed tests with no V4 identities or circuit-family special cases.
- Run the broad local regression and installed-KiCad fixtures.
- Review the staged diff with Prism, remediate findings, and seal the reviewed
  implementation before held-out validation.

## Phase 5: One-time validation and retirement

- Prove strict discovery and selected-cluster uplift first.
- Run the blind held-out final comparison exactly once.
- Enforce strict held-out uplift, no pass/unsafe regression, the frozen
  monotonic gap relation, replay, promotion, and all KiCad gates.
- Atomically publish complete success evidence, or publish only a failure audit
  that discloses no held-out content.
- Permanently block V4 updater modes after either completion or failure.
- Review staged changes with Prism, commit, and push; do not manually start or
  inspect GitHub Actions.
