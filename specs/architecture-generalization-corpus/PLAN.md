# Out-of-Distribution Architecture Generalization Plan

## Phase 0 — Freeze Before Production Changes

- Record the clean base commit.
- Author the six design and four adversarial behavior-only requirements.
- Add a strict manifest with per-file SHA-256 identities and forbidden-detail
  checks.
- Capture current deterministic search/simulation outcomes without modifying
  production synthesis.

## Phase 1 — Baseline And Gap Classification

- Run every case under one explicit bounded policy.
- Record topology/value/simulation/physical stop stages, stable codes,
  consumption, and evidence hashes.
- Group failures by reusable missing obligation, relationship, measurement,
  value derivation, repair, or physical rule.

## Phase 2 — Generic Electrical Closure

- Implement the smallest reusable graph and value operators needed by the
  frozen failures.
- Add trusted analyses and measurement contracts where the schema currently
  exceeds solver evidence.
- Add fail-closed rating, bias, thermal, stability, and SOA diagnoses before
  considering physical promotion.

## Phase 3 — Generic Physical Closure

- Lower only fully passing graphs.
- Correct placement, endpoint access, branch order, layer transitions, and
  routing from topology/geometry facts only.
- Preserve readable schematic conventions and deterministic replay.

## Phase 4 — Promotion And Preservation

- Promote at least five design cases twice through installed KiCad.
- Require connectivity, route completion, writer correctness, clean ERC,
  strict DRC, and zero round-trip differences.
- Prove stable fail-closed behavior for all adversarial cases.
- Run the complete short suite, prior architecture promotions, first held-out
  corpus, and simulation-grounded composition preservation shards locally.

## Phase 5 — Completion Audit

- Compare final results with the untouched baseline.
- Confirm production code contains no corpus identity or fixture-derived
  physical constants.
- Record hashes, gates, remaining unsupported boundaries, and exact local
  reproduction commands.

All phases are complete. The final evidence is recorded in
`PROMOTION_MATRIX.md`, `PRESERVATION_REPORT.md`, and `COMPLETION_AUDIT.md`.
