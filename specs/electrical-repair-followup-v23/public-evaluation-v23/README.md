## Execution contract

- Exactly 24 cases in canonical order, two fresh serial replays each. No resume,
  outcome-driven retry, corpus change, selection change, or budget adjustment.
- The only new numerical behavior is the sealed V23 stale op-amp clamp recovery.
  Exact model/backend prerequisites, solver-policy records, full electrical
  certificates, critical guards, and previously-passing-corner gates remain
  mandatory. Nonlinear workflows use the unchanged historical solver.
- Graph operators, search order, depth 4, beam 8, 4096 binding work, 128 charged
  simulation calls, and 4096 corners are unchanged from V22. The original
  simulation policy additionally bounds calls/corners. The V23 execution record
  separately binds its one recovery seed and finite additional-solve bound.
- Go 1.26.8, darwin/arm64, CGO=1, GOENV/GOWORK off, no GOFLAGS/GOEXPERIMENT
  overrides; installed KiCad 10.0.3 and the existing authenticated libraries.
  Native macOS access is required for zone refill. The six-hour process timeout
  is an infrastructure stop, never a capability outcome.
- Every passing synthesis must pass the unchanged installed-KiCad promotion in
  both outer replays, with two clean project roots per promotion. Require ERC,
  strict DRC, complete routing, connectivity, writer correctness, zero round-trip
  differences, and exact project replay. Numerical or lowering success alone is
  not a pass.
- Any non-capability error stops the run. Retain partial evidence without
  replacement. Recovery requires a separately recorded boundary; no silent retry.
  No held-out key/content access, new capability scope, or v1 admission is allowed.
