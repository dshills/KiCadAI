# Evidence-quality contract

This is a public, single-agent self-reviewed experiment, not independent or
blind validation. The data-quality review added full paired-input inventory
authentication, build/environment identity checks, explicit request timing and
safe local-error capture, and synthetic tests of resource-monitor failures.

## Grain and completeness

The primary board denominator is the eight IDs P01–P08. Four refusals and two
clarifications are separate behavioral criteria. W01/W02 paraphrases, fixed
answer turns, bounded diagnostic corrections and two downstream replays are
separate observations, never extra successful boards. The frozen corpus parser
rejects duplicate IDs and changed cardinalities. Every case remains in the
campaign and audit tables, including `not_run` after a campaign stop.

The read-only SCORING audit lists every clause and eight gates in original
order. Missing measurements, skipped stages, absent projects, unavailable RSS
or interrupted evidence cannot be reported as passing. Provider JSON claims
are not independent electrical evidence. Generated artifacts remain candidates
until source-bound semantic, electrical, physical and visual review passes.

## Identity and consistency

The freeze binds all acceptance/evaluator bytes, the production baseline and
the preparation source commit. Workers also embed the freeze-file digest.
The supervisor requires a clean build matching the current source revision,
fixed Go/Node/native-KiCad identities, fixed native-library index and unchanged
closed-loop resource policy. It verifies baseline catalog/model/capability
identities. Scoped final production improvements may change those last three;
the final snapshot records the resulting identities without changing the
evaluator or acceptance bytes. Installed libraries may not silently drift.
The library identity sets only `LibraryIndex.GeneratedAt` (collection time) to
the zero time before hashing; the unmodified full index is retained as gzip.

Case inventories authenticate every retained file. Paired controls reject any
modified or additional baseline file, and retain the baseline inventory digest.
Publication must bind the case inventories, resource files and request journal
in an outer inventory, so editing an inventory cannot conceal altered inputs.
Inventories authenticate retained bytes, not an external timestamp or signer.

## Resources and privacy

The shared append-only journal counts requests, retains uncertain reservations,
and applies frozen token-based **estimated** costs. It is not an invoice or a
guarantee of account-wide spend. No other task's API usage is included. The user
authorized these tests with the existing key. No authorization headers or key
values are retained. Exact credential/key-shaped response strings are redacted
at capture; any redaction affecting semantic evidence must be disclosed.

Sampled process-tree RSS is a lower bound on instantaneous peak memory, not a
continuous measurement. Invalid process samples fail closed. Native temporary
files disappearing during a storage sample are allowed; symlinks and all other
filesystem errors fail closed. Build, preflight snapshot and review resources
are separate from per-case work and must not be presented as free.

## Preregistered interpretation

Rail-voltage windows apply after startup settles and while the declared supply
is present, unless a case explicitly states a startup/off-state limit. Startup,
reset, reverse-input and partial-power safety are still separately mandatory.
The four-layer bound and perimeter accessibility are independently inspected
against the actual native board even when represented as provider context;
they are not discarded because the behavioral schema lacks a layout field.
ADC/clock/thermal provenance gaps remain failures if the selected evidence
cannot prove the requirement; physical plausibility alone is insufficient.

The same agent has seen P07/P08. Their details cannot motivate implementation
tuning; final claims are limited to this frozen corpus. Hardware fabrication,
firmware functionality and arbitrary-board generalization remain unvalidated.
