## Checks and observations

- The closed rectangular outline corresponds to the native 120×80 mm centerline. Gerber job and independent renderer bounds include its 0.1 mm stroke: 120.1×80.1 mm. All nine required Gerber layers parse; the bottom paste layer is empty, consistent with exclusively top-side SMD assembly.
- Top/bottom copper and drill overlays match the native routing and footprint locations. There are no apparent missing exported copper features or pad/drill registration shifts in the inspected views. This supplements the native zero-error ERC/strict-DRC/parity/unconnected checks; a visual raster is not a clearance measurement or electrical-connectivity proof.
- Complete top paste and top/bottom mask views were checked, plus sensor-area copper, paste and mask close-ups. The SHT31 layout shows eight perimeter lands and its grounded exposed land, with C5 nearby at (103.875,16.5) mm. The BMP280 layout retains its eight perimeter lands and original two local bypass capacitors. These are exported land patterns, not solder-joint or stencil-process performance claims.
- SHT31 has 70 plated holes: 12 at 0.200 mm, 35 at 0.300 mm, 11 at 0.350 mm and 12 at 1.000 mm. BMP280 has 73: the corresponding counts are 12, 38, 11 and 12. Native drill maps, the Excellon records and native-bound drill checks agree. Both NPTH files intentionally contain zero hits; their empty maps and separate parses were checked.
- Actual placement CSVs have 16 populated rows for SHT31 and 17 for BMP280. All are top-side. U2 is (100,-15) mm/0° for SHT31 and (86,-23) mm/0° for BMP280. The shared controller is (51,-30) mm/0°. C1/C2 are 90°; C3/R1/R2 are 180°; BMP280 C6 is -90°. The checker matches every reference, value, package, coordinate and rotation to the native footprint, not only this sample. The native Y axis is reversed in placement and drills.
- Full A3 native schematics and PCB previews were inspected. Their sensor identity, connectors, reset/boot, bypasses and pull-ups agree with the generated configurations. The controller's grouped ground pin labels remain crowded, and manufacturing silkscreen does not carry a complete set of component references/connector signal labels. Use the native project, BOM and placement data together; these are known documentation/assembly limitations, not silently repaired output.
- Within each family, all 15 non-placement manufacturing deliverables have identical timestamp-normalized hashes across profiles. The placement values of R3/R4 change as configured; their identity/geometry is independently checked for every profile. Thus the visual geometry review is reused only where actual bytes prove equivalence.

## Validator hardening

The previous drill checker ignored some executable commands after testing framing and comparing holes. New negative controls first reproduced 15 incorrect admissions, including incremental coordinates, coordinate offsets, routing/repeat commands, early stops, misplaced commands and duplicate definitions. The revised parser accepts only the requested KiCad metric-decimal, absolute, drill-only dialect and rejects unknown commands or data after its single terminal `M30`. It retains the explicit 0.00051 mm serialization tolerance.

Gerber declaration checks now reject duplicate/conflicting layer identities, units, formats and file polarity, extra identity suffixes, early/duplicate terminators and legacy modal/stop commands. Bundle tests exercise missing/corrupt layers, job stack/dimension errors, missing/extra/duplicate job entries and missing placement/drill files. **This remains a bounded format/declaration checker, not a complete Gerber geometry interpreter.** Independent rendering and native checks provide separate evidence.

All five new cases passed 14 checks twice, with no native-output repair. Focused Go tests, full-repository lint (zero issues) and full bounded offline regression passed; the regression took 38.252 seconds with provider keys removed. No live API requests were made and all 677 prior publication files remain unchanged. Updated remote CI is still pending.

## Reproducible review and limitations

`development/render-manufacturing.mjs` hashes original inputs before and after rendering and writes only a new review directory. It uses an isolated Gerbonara 1.6.3 environment, explicit eleven-file layer mapping, recorded dependency versions and `rsvg-convert`; it does not add a production dependency. The [Gerbonara CLI documentation](https://gerbolyze.gitlab.io/gerbonara/cli.html) describes the supported rendering and mapping operations. The installed raw renderer requires `side use` color keys, unlike its pretty-render options; the recipe includes explicit colors and rejects empty SVG content.

Warnings are retained, not suppressed: Gerbonara warns about KiCad's `G90` after the header and an unused extra RoundRect macro parameter. Its automatic metadata also labels populated drills as unknown plating and omits empty drill layers. The explicit render mapping binds intended plating, the production checker validates it against native geometry, and the NPTH file is parsed separately as empty. Rounded pad shapes were compared with the native previews. A pip cache-permission warning during dependency inventory is also retained. Earlier failed/incomplete review attempts remain in the cache and are not represented as passing inspections.

`development/compare-replay.mjs` preserves raw hashes and compares files in memory. It removes only named timestamp fields in Gerber, Excellon, Gerber-job JSON, drill reports and native SVG titles. Geometry, other metadata, units, layer assignments and BOM/configuration values remain significant. Six normalization tests prove date-only changes compare equal while representative body changes remain different and duplicate/missing timestamp fields fail. Per-run logs/reports/envelopes are not byte-replay deliverables; validation and export manifests are authenticated separately. KiCad's per-user `.kicad_prl` is excluded from publication.

Before a physical build, the assembler/fabricator must confirm orientation/pin 1, accepted coordinate conventions, laminate/finish/tolerances, stencil thickness/apertures and exposed-pad via solder-wicking treatment, sensor handling, soldering process and assembly inspection. Sparse silk, controller ground-label readability and whole-board electrical/thermal behavior require the documented engineering/bring-up follow-up. No order or paid evaluation is authorized by this record.
